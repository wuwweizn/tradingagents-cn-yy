# 会员LLM提供商授权批量导入导出功能

## 功能概述

会员管理模块现在支持批量导入和导出LLM提供商授权信息，管理员可以通过Excel或JSON文件批量管理会员的LLM提供商使用权限。

## 功能特性

### 1. Excel批量导入模板

- **新增列**：`LLM提供商权限`
- **格式**：多个提供商用逗号分隔，如：`dashscope, deepseek, openai`
- **说明工作表**：Excel模板包含「LLM提供商说明」工作表，列出所有可用的提供商代码和名称

### 2. Excel数据备份

- **包含列**：`LLM提供商权限`（包含所有会员的提供商授权信息）
- **格式**：多个提供商用逗号分隔
- **用途**：完整备份和恢复会员数据，包括提供商权限

### 3. JSON格式导出

- **完整数据**：包含所有会员信息，包括`provider_permissions`字段
- **格式**：数组格式，如：`["dashscope", "deepseek", "openai"]`

### 4. 导入功能增强

#### Excel导入
- **多列名支持**：自动识别`LLM提供商权限`、`提供商权限`、`provider_permissions`等列名
- **格式兼容**：支持逗号和分号分隔
- **自动验证**：验证提供商名称的有效性，忽略无效的提供商名称
- **错误提示**：显示无效的提供商名称，但不会阻止导入

#### JSON导入
- **格式验证**：支持数组和字符串格式
- **自动转换**：字符串格式自动转换为数组
- **有效性验证**：过滤无效的提供商名称

### 5. 导入预览增强

- **显示提供商权限**：在导入预览中显示每个会员的LLM提供商授权信息
- **友好显示**：使用中文名称显示提供商（如：阿里百炼、DeepSeek等）
- **未授权标识**：未授权的会员显示为"未授权"

## 使用说明

### 导出会员信息（包含LLM提供商权限）

1. 进入「会员管理」页面
2. 在「批量管理」区域，点击「导出会员信息」
3. 选择导出格式：
   - **Excel批量导入模板**：包含`LLM提供商权限`列，适合批量创建会员
   - **Excel数据备份**：包含所有会员的完整数据，包括提供商权限
   - **JSON格式**：完整的JSON数据，包含`provider_permissions`字段
4. 下载文件

### 导入会员信息（包含LLM提供商权限）

1. 进入「会员管理」页面
2. 在「批量管理」区域，点击「导入会员信息」
3. 上传Excel或JSON文件
4. 查看导入预览，确认LLM提供商权限信息
5. 选择导入模式：
   - **合并模式**：保留现有会员，新增或更新导入的会员
   - **替换模式**：完全替换所有会员数据
6. 点击「确认导入」

### Excel文件格式要求

#### 批量导入模板格式

| 列名 | 说明 | 示例 | 必填 |
|-----|------|------|------|
| 用户名 | 会员登录卡号/用户名 | user001 | 是 |
| 密码 | 登录密码（明文） | password123 | 是 |
| 角色 | 用户角色：user 或 admin | user | 是 |
| 权限 | 权限列表，用逗号分隔 | analysis, batch_analysis | 否 |
| LLM提供商权限 | 允许使用的LLM提供商，用逗号分隔 | dashscope, deepseek, openai | 否 |
| 点数 | 初始点数 | 10 | 否 |

#### 数据备份格式

| 列名 | 说明 | 示例 |
|-----|------|------|
| 用户名 | 会员登录卡号/用户名 | user001 |
| 密码哈希 | 密码哈希值 | $2b$12$... |
| 角色 | 用户角色 | user |
| 权限 | 权限列表，用逗号分隔 | analysis, batch_analysis |
| LLM提供商权限 | 提供商权限列表，用逗号分隔 | dashscope, deepseek, openai |

## 验证和错误处理

### 提供商名称验证

- 系统会自动验证提供商名称的有效性
- 无效的提供商名称会被忽略，但不会阻止导入
- 导入时会显示警告信息，列出所有无效的提供商名称

### 错误提示示例

- `user001: 无效的LLM提供商名称 invalid_provider（已忽略）`
- 如果多个用户有无效的提供商，会列出所有警告

### 兼容性

- **向后兼容**：如果Excel文件中没有`LLM提供商权限`列，导入时默认为空（未授权）
- **多列名支持**：支持`LLM提供商权限`、`提供商权限`、`provider_permissions`等多种列名
- **格式兼容**：支持逗号和分号分隔的提供商列表

## 注意事项

1. **提供商权限是可选的**：如果Excel中`LLM提供商权限`列为空，导入后会员将没有提供商权限（需要管理员手动授权）
2. **无效提供商会被忽略**：如果填写了无效的提供商名称，系统会自动忽略，但会显示警告
3. **导入后验证**：建议导入后检查会员的提供商权限是否正确设置
4. **备份重要数据**：在执行替换模式导入前，建议先导出当前数据作为备份

## 技术实现

### 导出功能
- Excel模板：在`批量导入模板`中添加`LLM提供商权限`列和示例值
- Excel备份：在`数据备份`中包含`LLM提供商权限`列
- JSON导出：包含完整的`provider_permissions`字段

### 导入功能
- Excel导入：支持多种列名，自动验证提供商名称有效性
- JSON导入：支持数组和字符串格式，自动转换和验证
- 错误处理：收集无效提供商名称，显示警告但不阻止导入

### 验证逻辑
- 有效提供商列表：`dashscope`, `deepseek`, `google`, `openai`, `openrouter`, `siliconflow`, `custom_openai`, `qianfan`
- 自动过滤：只保留有效的提供商名称
- 错误记录：记录所有无效的提供商名称，在导入时显示警告
